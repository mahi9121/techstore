# TechStore - E-Commerce Product Catalog

## Description

TechStore is a responsive e-commerce website developed using HTML5, CSS3, and JavaScript. It allows users to browse products, search items, filter products by category, and view a modern product catalog. The project follows a modular frontend architecture and demonstrates client-side routing, responsive design, and dynamic JavaScript functionality.

---

## Features

- Responsive Design
- Home Page
- Product Catalog
- Search Products
- Category Filter
- Shopping Cart Counter
- Wishlist Counter
- Product Ratings
- Client-side Routing
- Modular JavaScript
- Responsive Navigation

4. Browse products and test the website.
